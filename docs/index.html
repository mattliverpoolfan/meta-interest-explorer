          ③ 受眾重疊比對

          看似不相關、但受眾實際重疊的標籤。只算台灣受眾，比對需要幾分鐘，會持續更新。

          怎麼看這些數字
          • 標籤中屬種子：鎖定這個標籤時，打到的人有幾成也在種子受眾裡——投放時最直接的參考。
          • 種子中屬標籤：種子受眾裡有幾成也對這個標籤有興趣——用來理解受眾、發想素材角度。
          • 比隨機高幾倍（lift）：上面第一個數字，是隨機碰巧重疊的幾倍。1 倍代表跟巧合一樣，沒有關聯。Meta 給的人數是範圍，所以顏色看的是最悲觀情況：綠＝最悲觀仍 ≥ 2 倍；橘＝最悲觀仍 ≥ 1.2 倍；灰＝中間值有訊號，但可能只是估算誤差。滑鼠移到數字上可看範圍。
          • 會先略過台灣人數太少（數字不可靠）或太多（比不出訊號）的標籤，不浪費比對額度。
